# Movie App

Учебный проект, демонстрирующий навыки работы с Vue.

## Функциональность

- Просмотр каталога фильмов
- Поиск фильмов по названию
- Добавление фильмов в избранное
- Просмотр трейлеров
- Адаптивный дизайн
- Рейтинг фильма
- Детальная информация о фильмах

## Технологии

- **Frontend:** Vue 3, TypeScript
- **Стилизация:** CSS
- **Управление состоянием:** Pinia
- **Роутинг:** Vue Router
- **API:** The Movie Database (TMDB)
- **Иконки:** Vue Icons
- **Сборка:** Vite

## Установка и запуск

### Предварительные требования

- Node.js (версия 16 или выше)
- npm или yarn

### Установка зависимостей

```bash
npm install
# или
yarn install
```

### Запуск в режиме разработки

```bash
npm run dev
# или
yarn start
```

Приложение откроется по адресу [http://localhost:5173](http://localhost:5173)

### Сборка для продакшена

```bash
npm run build
# или
yarn build
```

Приложение использует [The Movie Database API](https://cinemaguide.skillbox.cc/) для получения данных о фильмах.
